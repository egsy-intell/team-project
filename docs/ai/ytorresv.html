AI Use Disclosure

Every thread and commit where Claude Code paired with Yai on this project

I'm Yai Torres, one of four people on this GRAD 50400 project (Group 14). This page is my individual pair-programming disclosure under the course's AI Tool Use Policy, which asks for exactly which tools were used and their tier, the history of each exchange, and how and why each tool was used — answered below, then backed by a real timeline instead of a paraphrase.

Tool & tier

Claude Code — Claude subscription — not the free or public tier.

How

Pair-programmed notebook implementation, debugging, lint/CI fixes, git housekeeping (merges/conflicts), and editorial passes on reader-facing prose.

Why

To work through unfamiliar parts of the stack step by step as a learning partner rather than a black box, and to move faster through mechanical work so more time went to modeling/analysis calls.
